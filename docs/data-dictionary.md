# 데이터 사전

이 문서는 저장소에서 직접 생성하는 필드만 정의합니다. 고용24 원응답의 전체 필드는 [공식 개발명세](https://www.work24.go.kr/cm/e/a/0110/selectOpenApiSvcInfo.do?fullApiSvcId=000000000000000000000000000093)를 기준으로 확인합니다.

## `data/processed/work24_jobs.csv`

| 필드 | 원 XML 태그 | 정의 |
|---|---|---|
| `job_class_code` | `jobClcd` | 고용24 직업분류코드 |
| `job_class_name` | `jobClcdNM` | 고용24 직업분류명 |
| `job_code` | `jobCd` | 상세 API 연결에 사용하는 직업코드 |
| `job_name` | `jobNm` | 직업명 |

## 상세구분 코드

| `section` | 내용 |
|---:|---|
| 1 | 요약 |
| 2 | 하는 일 |
| 3 | 교육·자격·훈련 |
| 4 | 임금·직업만족도·전망 |
| 5 | 능력·지식·환경 |
| 6 | 성격·흥미·가치관 |
| 7 | 업무활동 |

## 계보와 공개 범위

- `data/raw/work24/*.xml`: API에서 받은 원응답. 수집 시각은 UTC 파일명으로 기록합니다.
- `data/processed/work24_jobs.csv`: 목록 응답에서 위 네 필드만 정규화한 파생자료입니다.
- 인증키는 쿼리에는 쓰이지만 파일·로그·예외 메시지에는 기록하지 않습니다.
- 원응답의 외부 공개는 고용24 승인 조건과 저작권·이용조건을 확인한 뒤 결정합니다.
