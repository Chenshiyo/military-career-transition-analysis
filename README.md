# 군사특기–민간직무 과업·역량 대응 분석

> **Military Specialty to Civilian Job Mapping**  
> 육군의 공개 군사특기 임무를 민간의 표준 직무 언어로 번역하며 재현성을 목표로 하는 공개데이터 연구입니다.

## 한눈에 보기

이 프로젝트는 병무청의 육군 군사특기별 **공개 임무 설명**, 국가직무능력표준(NCS)의 **능력단위**, 고용24의 **직업·직무정보**를 연결해 다음 질문에 답하려는 연구입니다.

> 군 복무 중 수행한 과업은 어떤 민간 직무 역량으로 번역될 수 있으며, 원활한 전환을 위해 어떤 역량을 추가로 보완해야 하는가?

분석 결과는 특기별 민간직무 후보와 근거, 과업·역량 중첩도, 공개 문서상 추가 확인 항목을 담은 **과업·역량 대응 지도**로 제시할 예정입니다. 개인의 실제 취업 결과를 추적하거나, 군 복무가 취업률·임금에 미치는 인과효과를 추정하는 연구는 아닙니다.

## 연구 질문

1. 공개된 군사특기 임무는 어떤 NCS 능력단위와 직접 연결되는가?
2. 특기별로 내용상 대응하는 민간 직무의 폭과 연결의 직접성은 어느 정도인가?
3. 공개 임무 설명만으로 확인되지 않아 추가 확인 또는 교육 검토가 필요한 항목은 무엇인가?
4. 자동 매칭 결과는 사람의 근거 기반 판정과 어느 정도 일치하는가?

## 공식 데이터

| 데이터 | 활용 항목 | 공식 출처 |
|---|---|---|

| 고용24 직업·직무정보 | 승인 후 API 명세와 실제 응답에서 확인되는 직업명·직업 설명·수행직무 등의 제공 항목 | [고용24 Open API](https://www.work24.go.kr/cm/e/a/0110/selectOpenApiSvcInfo.do?fullApiSvcId=000000000000000000000000000093) |

2026-08-15 수집본 기준으로 병무청 육군 기술행정병 특기 147개와 NCS 능력단위 13,442개를 점검했습니다. 기관 화면의 안내 문구와 실제 응답 건수는 기준 시점에 따라 달라질 수 있으므로, 모든 결과에 **수집일·원자료 버전·실제 관측 건수**를 함께 기록합니다.

## 분석 설계

병무청 자료는 군 과업의 출발점, NCS는 과업을 비교하기 위한 공통 역량 언어, 고용24는 민간 직무의 수행내용을 확인하는 자료로 사용합니다. 기관 간 공식 대응표가 존재한다고 가정하지 않으며, 연결 결과는 이 연구의 후보 생성과 사람 검토를 거쳐 구축합니다.

1차 분석단위는 `군사특기 공개 과업 × NCS 능력단위`이며, 이를 고용24 직무 설명과 비교한 뒤 `군사특기 × 민간직무` 수준으로 집계할 예정입니다. 현재 생성된 360개는 최종 직무 연결이 아니라 `군사특기 × NCS 능력단위`의 1차 후보쌍입니다.

```text
군사특기 공개 임무
        ↓ 문장 정제·과업 분해
NCS 능력단위 후보 생성
        ↓ 사람의 근거 기반 0·1·2 판정
민간 직무 후보 연결
        ↓ 누락 역량 비교
특기–민간직무 과업·역량 대응 지도
```

자동 유사도는 검토할 후보를 줄이는 용도로만 사용합니다. 현재 후보 생성은 군 임무 원문과 NCS 능력단위명을 사용했습니다. 최종 연결은 공식 NCS 능력단위 정의·수행준거와 고용24 실제 응답 항목을 추가 확보한 뒤, 코드북 작성 → 두 명의 코더 독립 판정 → 불일치 조정 순으로 확정할 계획입니다.

| 핵심 지표 | 정의 |
|---|---|
| 역량 중첩도 | 특기의 공개 과업 중 해당 민간직무 NCS와 연결된 과업의 비율 |
| 연결 직접성 | 0(무관)·1(보조)·2(핵심)의 사람 판정 |
| 코더 일치도 | 0·1·2 순서형 판정에 대한 선형 가중 Cohen's κ |
| 전환 직무 다양성 | 기준을 통과한 민간직무 후보 수와 직무군 수 |
| 공개 문서상 미확인 항목 | 민간직무 핵심 NCS 중 공개 군 임무 설명에서 확인되지 않은 능력단위. 개인의 실제 역량 부족을 뜻하지 않음 |

## 현재 파일럿

- 통신·네트워크, 차량·수송, 보급·물류, 급식·의료지원, 시설·전기, 장비정비 분야의 기술특기 24개. 병무청에 공개 임무 설명이 있고 작전·편제·부대 위치·장비 현황을 요구하지 않는 항목만 파일럿에 포함
- 특기당 NCS 상위 후보 15개, 총 360개 후보쌍 생성
- 자동 후보에서 타당해 보이는 연결과 오연결 사례를 모두 관찰했으며, 이를 바탕으로 사람 검토 절차를 포함
- 고용24 직업·직무정보 API 승인 후 민간 직무 설명을 결합할 예정

현재 수치는 **초벌 데이터 점검과 파일럿 후보 생성 결과**이며, 확정된 정책 효과나 취업 성과가 아닙니다.

## 예정 산출물

- `특기 × 민간직무` 대응표와 연결 근거
- 특기별 역량 중첩도·직접성·전환 직무 다양성
- 공개 임무 설명에서 확인되지 않아 추가 확인 또는 교육 검토가 필요한 NCS 능력단위 요약
- 자동 매칭의 오류 유형과 사람 검토 결과
- 육군 기고문용 도표와 정책 제안
- 수집일·버전·처리 과정을 포함한 재현 코드와 데이터 사전

## 고용24 API 활용 계획

- 현재 API 승인 전이며 고용24 데이터가 결합된 분석 결과는 없습니다.
- 승인 후 직업·직무정보 API의 명세와 실제 응답을 먼저 대조하고, 제공이 확인된 직업명·직업 설명·수행직무 등을 군사특기–NCS 후보와 비교합니다.
- 개인화, 채용 중개, 개인의 취업 추적, 상업적 재판매에는 사용하지 않습니다.
- 인증키는 환경변수로 관리하고 `.env` 등 로컬 설정 파일을 버전 관리에서 제외합니다.
- 원응답의 저장·공개 범위는 고용24 이용조건을 따릅니다. 재배포가 제한되면 수집 코드, 출처, 필드 정의, 집계된 파생통계만 공개합니다.
- 호출량, 갱신 주기, 캐시 정책은 승인 조건과 서비스 제한을 준수합니다.

### 수집 코드 실행

고용24에서 직업정보 API 인증키가 발급된 뒤 아래 순서로 실행합니다. 이 저장소는 외부 패키지 없이 Python 3.11 이상에서 동작합니다.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e .
$env:WORK24_AUTH_KEY = "발급받은_인증키"

# 직업 목록 XML과 정규화 CSV 생성
work24-jobs list

# 특정 직업의 '하는 일' 상세 XML 수집
work24-jobs detail 직업코드 --section 2
```

`WORK24_AUTH_KEY`는 커밋하지 않습니다. 목록 원문은 `data/raw/work24/`, 정규화 목록은 `data/processed/work24_jobs.csv`에 생성되며 두 경로의 생성물은 기본적으로 Git에서 제외됩니다. 필드 정의와 상세구분은 [`docs/data-dictionary.md`](docs/data-dictionary.md)를 참고하십시오.

인증키 없이 구조만 검증하려면 다음 테스트를 실행합니다.

```powershell
$env:PYTHONPATH = "src"
python -m unittest discover -s tests -v
```

## 해석 범위와 안전 원칙

- 개인 식별정보, 개인별 복무기록, 취업이력은 수집하거나 결합하지 않습니다.
- 부대 위치·편제·병력·장비 현황·실제 작전 및 훈련정보를 다루지 않습니다.
- 공개된 일반 임무 설명만 사용하며, 민감하거나 작전적인 세부정보는 분석 대상에서 제외합니다.
- 특기–직무 연결은 공개 문서에서 확인되는 **과업·역량의 내용상 대응 정도**를 뜻하며 실제 취업확률, 채용 적합도, 임금 상승, 자격 인정 또는 채용 보장을 뜻하지 않습니다.
- API 키와 인증정보는 저장소에 올리지 않습니다.
- 원자료의 이용조건과 재배포 가능 범위를 확인하고, 제한이 있는 자료는 내려받기 코드와 출처만 공개합니다.

## 기대 활용

이 연구는 전역 예정 장병에게는 군 경험을 민간 역량 언어로 설명할 근거를, 육군에는 특기교육과 전직교육 사이에서 추가 확인할 항목을 점검할 자료를 제공하는 것을 목표로 합니다. 최종 제안은 “자격증 수를 늘리자”에 머무르지 않고, **공개 군 과업–민간 표준역량–추가 확인·교육**을 하나의 경로로 연결하는 데 초점을 둡니다.

## 연구 상태

현재 단계는 **파일럿 분석 및 데이터 접근 준비**입니다. 고용24 직업·직무정보 결합, 2인 코딩, 일치도 검증을 마친 뒤 본 결과를 공개합니다.
